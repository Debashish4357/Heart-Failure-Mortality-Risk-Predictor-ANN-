# Heart-Failure-Mortality-Risk-Predictor-ANN-
Heart Failure Mortality Risk Predictor (ANN)A full-stack, machine-learning-driven clinical decision-support prototype.OverviewThis project provides a robust, end-to-end Machine Learning pipeline and web application designed to estimate mortality risk for heart failure patients at the point of clinical assessment. It bridges rigorous Advanced Data Science methodologies with a production-ready software architecture to deliver a mathematically calibrated, probability-first risk estimate for clinicians.key  Key FeaturesStrict Data Leakage Prevention: Explicitly excludes retrospective follow-up time variables from the deployment feature set to ensure real-world predictive validity.  Deep Learning vs. Baseline: Features a custom PyTorch Deep Artificial Neural Network (ANN) rigorously benchmarked against a Logistic Regression baseline model.  Robust Validation: Evaluated using Stratified 5-Fold Cross-Validation, measuring AUROC, Sensitivity, and Specificity.  Mathematical Calibration: Utilizes out-of-fold predictions, calibration curves, and Brier scores to ensure the output probabilities are accurate and trustworthy.  Clinical Dashboard: A React frontend styled with Tailwind CSS that enforces a "probability-first" display, strictly avoiding arbitrary or mathematically unjustified categorical risk labels.  Secure Backend: A stateless FastAPI prediction service backed by PostgreSQL for JWT-based user authentication, session management, and prediction history.  Tech StackMachine Learning: PyTorch, scikit-learn, pandas, NumPy, Matplotlib  Backend: Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic  Frontend: JavaScript, React, Tailwind CSS  Deployment: Docker, docker-compose  Local SetupClone the repository and ensure Docker is installed on your machine.Create a .env file in the root directory based on .env.example, including your PostgreSQL database credentials and JWT secrets.  Run docker-compose up --build to spin up the React frontend, FastAPI service, and PostgreSQL database simultaneously.  Access the clinical dashboard at http://localhost:3000 and the API documentation at http://localhost:8000/docs.Disclaimer: This system provides a machine-learning-based mortality-risk estimate for research and decision-support purposes. It is not a diagnosis and should not replace professional clinical judgment.
